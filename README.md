# Atividade – Design Profissional

Este repositório reúne as atividades desenvolvidas na disciplina de Design Profissional, com foco na organização e apresentação profissional do GitHub.

A atividade foi dividida em duas etapas:

## Etapa 1 – Pesquisa e benchmarking

Foi realizada uma pesquisa de 10 perfis profissionais do GitHub relacionados à área de Inteligência Artificial. A análise considerou a apresentação dos perfis, os projetos fixados, a organização dos repositórios, a documentação e a atividade dos desenvolvedores.

O relatório completo está disponível em [Etapa 1 – Relatório de Pesquisa](Etapa%201/Relatorio-Pesquisa.md).

## Etapa 2 – Organização do GitHub

Nesta etapa, foram aplicadas melhorias no perfil pessoal e na organização dos repositórios, buscando apresentar melhor meus conhecimentos, estudos e atividades acadêmicas.

A descrição das ações realizadas está em [Etapa 2 – Organização Profissional](Etapa%202/README.md).

## Objetivo

O objetivo da atividade é aprender a utilizar o GitHub não apenas para armazenar códigos, mas também como uma ferramenta de apresentação profissional, organização de projetos e divulgação dos conhecimentos desenvolvidos durante a formação em Engenharia de Software.
